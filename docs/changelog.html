Release history
Overview Release notes Roadmap

PCSST now has a broader utility release, not just a starter surface.

`v0.3.0` adds CSS-only variants, richer spacing and sizing, positioning, stronger flex and grid controls, container queries, expanded docs, and the same verification and packaging flow.

Release timeline

Major milestones so far.

Foundation phase Established the initial PCSST token system, layout helpers, component set, and docs scaffold before the current public release track.
v0.2.0 Foundation Added responsive tier utilities, pill navs, toolbars, stat strips, timelines, progress, app shells, and multi-page docs.
v0.3.0 Current Introduces authored `hover:*`, `md:*`, `max-*`, and `@*` variants plus broader spacing, sizing, position, and flex/grid utilities without adding tooling.
Next Move toward stronger accessibility primitives, denser data-display components, and deeper form-state coverage inside the CSS API.

What changed in the preview

New in the current docs set.

  • Authored variants: hover:*, focus-visible:*, dark:*, sm/md/lg/xl/2xl:*, max-*, and @*.
  • Expanded utilities: margin, sizing, positioning, display, overflow, color, transition, and richer flex/grid controls.
  • Docs refresh: overview, guide, and library reference now demonstrate the `v0.3.0` API directly.
  • Automation baseline stays intact: verify, site export, package scripts plus GitHub workflows.

Repository automation

GitHub workflow coverage

  • CI
    Run verification on pushes and pull requests. Ensures the framework builds and docs references stay intact.
  • PG
    Export and deploy the docs site to GitHub Pages. The site/ artifact is generated automatically.
  • RL
    Package and publish on version tags. Tagged releases verify the version, create an archive, and optionally publish to npm.
