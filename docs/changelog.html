Release history
Latest docs Changelog Stable 0.1.0

PCSST now has a release shape, not just a demo.

The framework release track now includes responsive utilities, expanded docs, verification scripts, site export, packaging, and GitHub automation for CI, Pages, and tagged releases.

Release timeline

Major milestones so far.

v0.1.0 Foundation Shipped the initial PCSST token system, layout helpers, component set, and docs scaffold.
v0.2.0 Current Added responsive tier utilities, pill navs, toolbars, stat strips, timelines, progress, app shells, and multi-page docs.
Next Move toward stronger accessibility primitives, more data-display components, and a formal plugin ecosystem around PCSST.

What changed in the preview

New in the current docs set.

  • Responsive tiers: .sm-*, .md-*, and .lg-* utilities.
  • Expanded components: pill nav, toolbar, stat strip, timeline, progress, command card, kpi card, app shell.
  • New docs pages: getting started, themes, showcase, and changelog.
  • Automation: verify, site export, package scripts plus GitHub workflows.

Repository automation

GitHub workflow coverage

  • CI
    Run verification on pushes and pull requests. Ensures the framework builds and docs references stay intact.
  • PG
    Export and deploy the docs site to GitHub Pages. The site/ artifact is generated automatically.
  • RL
    Package and publish on version tags. Tagged releases verify the version, create an archive, and optionally publish to npm.
