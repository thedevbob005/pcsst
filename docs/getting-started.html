Get PCSST running in one short loop.

The framework is just CSS. `v0.4.0` expands the utility surface and adds authored state, range, and container-query variants without introducing a class generator.

Framework commands Local workflow
python3 scripts/build.py python3 scripts/verify.py python3 scripts/dev.py python3 scripts/export_site.py
Repository shape
  • src/pcsst.css is the authoring source.
  • dist/ holds built distributables.
  • docs/ is the product-style docs site.
  • scripts/ contains build, verify, export, and package tools.

1. Install the stylesheet

Start with one CSS import.

<link rel="stylesheet" href="dist/pcsst.css" />

PCSST is designed to be consumed directly. There is no compiler requirement for the framework itself.

2. Compose your first section

Use named layout primitives before touching one-off utilities.

<section class="shell section stack stack-5"> <span class="badge badge--accent">PCSST</span> <h1 class="display">Ship UI with plain CSS.</h1> <p class="lead">Tokens, layouts, and components in one layer.</p> <div class="cluster"> <a class="button button--primary" href="#">Launch</a> <a class="button button--ghost" href="#">Read docs</a> </div> </section>

3. Learn the variant model

Write the responsive and state tokens directly.

Treat the base classes as mobile-first. Layer on responsive tokens like md:grid-cols-3, range controls like max-lg:flex-col, state tokens like hover:bg-accent-soft, and container variants like @md:grid-cols-2 when the interface needs to adapt. The older .sm-*, .md-*, and .lg-* helpers still work as compatibility shorthands.

4. Move into product surfaces

Start with components, not blank divs.

  • 1
    Use .toolbar for action clusters. Toolbars give filters, actions, and metadata a shared surface.
  • 2
    Use .stat-strip and .kpi-card for metrics. They handle grouping, borders, and density in one step.
  • 3
    Use .app-shell for docs and dashboards. A sidebar and main surface arrive with consistent spacing and depth.

5. Run the repo loop

Build, verify, export, package.

Build Generate dist/pcsst.css and dist/pcsst.min.css.
Verify Compile Python tools and validate docs references.
Export Stage a GitHub Pages-ready static site in site/.
Package Create a release archive in releases/.
