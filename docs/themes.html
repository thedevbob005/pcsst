PCSST themes are runtime CSS variables, not a separate build step.

Switch the framework voice by changing data-pcsst-theme or overriding tokens directly. The markup stays the same.

Scoped theme usage

Apply themes to a subtree.

<main data-pcsst-theme="midnight"> <div class="app-shell">...</div> </main>

Use this when one application area should diverge from the page shell without changing all surrounding content.

Custom theme authoring

Override tokens directly.

[data-pcsst-theme="orchid"] { --pc-color-page: #fcf6f7; --pc-color-panel: #fffdfd; --pc-color-ink: #2e2433; --pc-color-accent: #176b86; --pc-color-brand: #d56472; --pc-color-highlight: #c5a035; }

The framework components pick up the new voice automatically because they resolve through PCSST variables.
