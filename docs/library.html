Tokens

Colors, spacing, typography, radii, and depth are all custom properties.

Override them at :root or scope them to any subtree with data-pcsst-theme.

Accent --pc-color-accent
Brand --pc-color-brand
Panel --pc-color-panel
Highlight --pc-color-highlight
Category Examples Purpose
Typography --pc-font-sans, --pc-font-display Body copy, display headings, code blocks, and interface labels.
Spacing --pc-space-1 to --pc-space-8 Rhythm shared by cards, stacks, fields, and app shells.
Color --pc-color-* Surfaces, feedback states, brand direction, and theming.
Shape --pc-radius-*, --pc-shadow-* Consistent surface hierarchy and touch target feel.

Responsive

Use literal breakpoint tokens like md:grid-cols-3 and max-lg:flex-col.

PCSST keeps responsive behavior readable without hiding it behind tooling. `v0.4.0` adds authored breakpoint and range variants, while the older .sm-*, .md-*, and .lg-* helpers remain available.

Token Examples Intent
Viewport breakpoints sm:*, md:*, lg:*, xl:*, 2xl:* Promote layout, density, and sizing as the viewport expands.
Range targeting max-md:*, max-lg:*, max-xl:* Constrain utilities to a breakpoint ceiling without custom media rules.
Compatibility tiers .sm-grid-2, .md-grid-3, .lg-pad-7 Preserve the original PCSST tier helpers for existing markup.

Variants

State, dark, and container-query variants are authored directly in CSS.

Write the class token literally in markup. PCSST targets exact class names like hover:bg-accent-soft, focus-visible:outline-highlight, dark:bg-panel-inverse, and @md:grid-cols-2 with plain selectors.

Midnight scoped dark variant
<button class="hover:bg-accent-soft hover:text-accent focus-visible:outline-2 focus-visible:outline-highlight focus-visible:outline-offset-2">...</button> <div data-pcsst-theme="midnight" class="dark:bg-panel-inverse dark:text-page">...</div> <div class="@container"> <div class="grid gap-4 @md:grid-cols-2 @max-md:grid-cols-1">...</div> </div>
Family Examples Use
State hover:bg-accent-soft, focus:border-accent, disabled:opacity-50 Handle interaction states without leaving the utility layer.
Status .is-loading, .is-invalid, .is-valid, .is-active Authoritative UI states for components and forms.
Dark dark:bg-panel-inverse, dark:text-page Scope overrides to data-pcsst-theme="midnight" using the same markup.
Container @container, @md:grid-cols-2, @max-lg:flex-col Adapt components to the size of their parent instead of the whole viewport.

Utilities

Utilities now cover the core layout and state surface, not just spacing trim.

Group Examples Use
Type .display, .text-lg, .font-mono, .tracking-wide Fast hierarchy, text sizing, and type voice without custom selectors.
Color and surface .surface-1, .bg-panel, .text-danger, .border-accent Named surfaces plus utility-grade background, text, and border control.
Space .p-5, .mx-auto, .gap-4, .pad-y-4 Targeted spacing when layout objects are not enough, with legacy aliases intact.
Sizing and position .w-full, .max-w-measure, .relative, .top-4 Size, place, and anchor UI elements without dropping to bespoke CSS.
Flex and grid .flex, .items-center, .grid-cols-4, .col-span-2 Move beyond layout objects when a component needs direct flex or grid control.
Motion and state .transition-transform, .hover:shadow-md, .focus-visible:outline-2 Add interaction affordances with stock classes instead of custom one-off selectors.
Flexbox & Grid Plus .flex-grow, .grid-cols-12, .order-first, .justify-self-center Fine-grained control over flex and grid children, including 12-column grid support.
Media & Layering .aspect-video, .object-cover, .z-10 Manage element proportions, image fitting, and stack order.
