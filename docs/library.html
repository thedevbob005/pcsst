Tokens

Colors, spacing, typography, radii, and depth are all custom properties.

Override them at :root or scope them to any subtree with data-pcsst-theme.

Accent --pc-color-accent
Brand --pc-color-brand
Panel --pc-color-panel
Highlight --pc-color-highlight
Category Examples Purpose
Typography --pc-font-sans, --pc-font-display Body copy, display headings, code blocks, and interface labels.
Spacing --pc-space-1 to --pc-space-8 Rhythm shared by cards, stacks, fields, and app shells.
Color --pc-color-* Surfaces, feedback states, brand direction, and theming.
Shape --pc-radius-*, --pc-shadow-* Consistent surface hierarchy and touch target feel.

Responsive tiers

Use .sm-*, .md-*, and .lg-* classes for common breakpoint changes.

PCSST keeps responsive behavior readable instead of burying it in cryptic class chains.

Tier Examples Intent
Small .sm-grid-2, .sm-pad-5 Early layout promotion for tablets or wider phones.
Medium .md-grid-3, .md-shell-wide Main breakpoint for dashboard, docs, and landing layouts.
Large .lg-grid-4, .lg-pad-7 Expand density and spacing for wide workspaces.

Utilities

Utilities stay descriptive and system-oriented.

Group Examples Use

Space .pad-5, .pad-y-4, .gap-3 Targeted spacing when layout objects are not enough.
Text .center, .text-left, .muted Simple alignment and hierarchy control without long selector chains.
